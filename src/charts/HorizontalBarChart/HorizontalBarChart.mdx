# HorizontalBarChart

Barras horizontales para rankings con etiquetas largas. Usa `@ant-design/plots` (`Bar`).

**Referencia:** `Dashboard-Comps/Widget Gallery.html → HBarSVG`

## Cuándo usar

- Rankings de agentes, campañas o departamentos donde los nombres son largos.
- Usar `sort="desc"` + `maxItems` para mostrar el top-N.
- Para categorías cortas o comparación temporal usa `BarChart`.

<Canvas of={HorizontalBarChartStories.Ranking} />

## Accesibilidad

`role="img"` con `aria-label` obligatorio (vía `ChartFrame`). Tabla oculta con los datos disponible para lectores de pantalla.
