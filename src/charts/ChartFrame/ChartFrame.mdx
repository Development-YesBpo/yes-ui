# ChartFrame

Envoltura compartida por todos los gráficos de `@yes/ui`. Aplica `role="img"` + `aria-label`, gestiona carga (`Skeleton`), estado vacío (`EmptyState`) y expone los datos a lectores de pantalla mediante una tabla oculta.

**Referencia:** `Dashboard-Comps/Widget Gallery.html`

## Cuándo usar

Nunca se usa directamente desde una aplicación. Cada componente gráfico lo compone internamente.

- Pasar `loading` mientras los datos llegan desde la API.
- Pasar `isEmpty` cuando la consulta no retorna filas.
- Pasar `srTable` con los datos para accesibilidad completa.

<Canvas of={ChartFrameStories.Loading} />

## Accesibilidad

- El contenedor lleva `role="img"` y `aria-label` obligatorio.
- La tabla oculta (`srTable`) expone todos los datos a tecnología asistiva sin afectar el render visual.
