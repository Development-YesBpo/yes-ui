# AreaChart

Áreas apiladas (`@ant-design/plots` `Area`). Referencia: `Widget Gallery.html → AreaSVG`.

**Cuándo usar:** composición + volumen total simultáneos. Para una sola métrica usa `LineChart`.

## Props
`data`, `xField`, `yField`, `seriesField`, `stacked` (default true), `ariaLabel` (obligatorio),
`height`, `showLegend`, `loading`. Accesibilidad vía `ChartFrame` (`role="img"` + tabla oculta).
