# AreaChart

Áreas apiladas para visualizar composición y volumen total simultáneamente. Usa `@ant-design/plots` (`Area`).

**Referencia:** `Dashboard-Comps/Widget Gallery.html → AreaSVG`

## Cuándo usar

- Distribución de volumen por canal a lo largo del tiempo (Teléfono / WhatsApp / Chat).
- Cuando importa tanto la proporción como el total.
- Para una sola serie sin apilamiento usa `LineChart`.

<Canvas of={AreaChartStories.Stacked} />

## Accesibilidad

`role="img"` con `aria-label` obligatorio (vía `ChartFrame`). Tabla oculta con los datos disponible para lectores de pantalla.
