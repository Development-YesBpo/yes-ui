# BarChart

Barras verticales para comparar categorías. Usa `@ant-design/plots` (`Column`).

**Referencia:** `Dashboard-Comps/Widget Gallery.html → BarSVG`

## Cuándo usar

- Comparación de pocas categorías (campañas, canales, períodos).
- Con `colorByField` para colorear cada barra con el tono de la serie.
- Con `grouped` para barras agrupadas lado a lado.
- Para rankings con etiquetas largas (nombres de agentes) usa `HorizontalBarChart`.

<Canvas of={BarChartStories.Default} />

## Accesibilidad

`role="img"` con `aria-label` obligatorio (vía `ChartFrame`). Tabla oculta con los datos disponible para lectores de pantalla.
