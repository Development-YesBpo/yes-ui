# BarChart

Barras verticales (`@ant-design/plots` `Column`). Referencia: `Widget Gallery.html → BarSVG`.

**Cuándo usar:** comparación por categoría (pocas categorías).
Para rankings con muchas categorías y etiquetas largas usa `HorizontalBarChart`.

## Props
`data`, `xField`, `yField`, `colorByField`, `grouped`, `ariaLabel` (obligatorio), `height`,
`showValues` (default true), `loading`. Accesibilidad vía `ChartFrame`.
