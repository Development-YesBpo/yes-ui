# LineChart

Serie temporal simple con línea suavizada y relleno de área opcional. Usa `@ant-design/plots` (`Line`).

**Referencia:** `Dashboard-Comps/Widget Gallery.html → LineSVG`

## Cuándo usar

- Evolución de una métrica en el tiempo (conversaciones por día, CSAT semanal).
- Hasta 4 series simultáneas con `seriesField`.
- Para composición de volumen usa `AreaChart`; para comparación por categoría usa `BarChart`.

<Canvas of={LineChartStories.Default} />

## Accesibilidad

`role="img"` con `aria-label` obligatorio (vía `ChartFrame`). Tabla oculta con los datos disponible para lectores de pantalla.
